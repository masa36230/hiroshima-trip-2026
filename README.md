# 海と祈り、おいしい広島。

2026年8月6日〜9日の広島3泊4日旅行を、夫婦で共有するためのモバイルファーストな旅程サイトです。

## ローカル表示

```bash
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開きます。

## 構成

- `index.html` — 旅程・食事・予約チェックリスト
- `styles.css` — レスポンシブデザイン、印刷スタイル
- `script.js` — スクロール演出、共有、カウントダウン、予約チェックの端末内保存
- `assets/` — オリジナルのキービジュアルとUnsplash写真
